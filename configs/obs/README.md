# OBS Setup

Use this folder for OBS scene collection notes, audio filter settings, and recording/streaming profiles.

Good things to document:

- Mic filters: noise suppression, expander/noise gate, compressor, limiter
- Desktop audio filters and monitoring choices
- Scene collection names and purposes
- Recording format and audio track mapping
- Streaming bitrate, encoder, and canvas/output resolution

Do not commit stream keys or account tokens.
